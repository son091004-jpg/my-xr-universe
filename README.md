# my-xr-universe

XR 포트폴리오 · GitHub 실습 템플릿

강사용 배포 저장소입니다. 학생에게는 `student/index.html`을 배포하고, 학생 각자의 기존 저장소 최상위에 `index.html`로 업로드합니다. 루트 화면의 GitHub 링크는 강사 계정으로 연결됩니다.

> 닉네임과 프로젝트 설명을 나의 내용으로 바꾸세요.

## 실행

`index.html`을 더블클릭하면 실행됩니다. API 키, 설치, 빌드 과정이 없습니다.

GitHub에서는 기존 `my-xr-universe` 저장소의 루트에 index.html을 업로드합니다.

Settings → Pages → Deploy from a branch → main → /(root) → Save.

## 수정

index.html 맨 위 MY_PROFILE의 6개 항목만 변경합니다.

자세한 절차: [학생 가이드](docs/STUDENT_GUIDE.md).

강사 예시: [instructor/index.html](instructor/index.html).

심화용 분리본은 advanced 폴더의 파일 4개를 함께 사용합니다.
